Local modification: added #pragma clang system_header to preserve the diagnostic
handling used when this header is loaded from Clang's builtin include directory.

C++ bots can include <wasm_simd128.h> to use v128_t and wasm_* intrinsics.
The bot CMake configuration enables -msimd128. Custom build systems must
enable this compiler option as well.
